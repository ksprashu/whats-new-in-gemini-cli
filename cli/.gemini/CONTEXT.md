# Context Constraints and Standards

- **Core Framework**: Python using `uv` package manager and virtual environments.
- **AI SDK**: Use `google-genai` for all Gemini interactions, as mandated for Python.
- **GitHub API**: For accessing Pull Requests and Issues related to changelogs.
- **Execution Environment**: Background agents triggered periodically (e.g. GitHub Actions or Cron).
- **Output Format**: Markdown guides (Walkthrough, How-To, Feature Summary, Background).
