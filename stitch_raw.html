Multi-turn chat context

Maintain context across multiple prompts in your terminal session.

auto_awesome Feature Summary

This update introduces persistent memory for chat sessions. Previously, the CLI treated every prompt as a new session. With v0.29.0, the CLI now leverages local caching to store conversation history, allowing for more natural, multi-turn dialogues directly from your command line.

  • Session Persistence: Context is saved automatically in ~/.gemini/sessions.
  • Context Flags: New flags to clear or resume specific sessions.
  • Token Optimization: Smart truncation of old history to manage context window limits.
info

Background & Context

Many developers requested the ability to refine code generation iteratively without re-pasting previous snippets. This PR (#402) implements a lightweight sliding window context manager that balances token usage with conversation coherence.

How-To Guide

To start a new interactive session, simply use the chat command without arguments.

Terminal 
$ gemini chat --new
? Starting new session: sess_01HG8...

You: Write a Python function to calculate Fibonacci numbers.
Gemini: Here is a simple recursive implementation...

You: Now make it iterative.
Gemini: Sure! Here is the iterative version...

You can also resume a specific session by ID: 

$ gemini chat --resume sess_01HG8
