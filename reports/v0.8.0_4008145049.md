# 🚀 What's New: The Gemini CLI Extension Ecosystem

**Release:** Gemini CLI v1.x (Extensions Update)
**Command:** `gemini extensions install`

---

## 1. Feature Summary
The Gemini CLI is evolving from a standalone tool into a platform. With the new **Extensions Manager**, developers can now expand the CLI’s capabilities by installing community-driven commands or building their own custom workflows.

The core of this release is the `gemini extensions install` command, which introduces two primary methods for extension acquisition:
*   **Remote Installation:** Directly from public GitHub repositories.
*   **Local Installation:** From a local folder path (enabling rapid development and side-loading).

## 2. Background & Context
### Why this change?
As the Gemini CLI adoption grew, our issue tracker saw an influx of requests for niche features specific to certain frameworks, languages, or specialized workflows. Trying to bake every request into the core binary would result in a bloated, hard-to-maintain tool.

### The Problem
Previously, if a user wanted to script a complex interaction with Gemini (e.g., "Review this specific PR and verify against our internal style guide"), they had to wrap the CLI in bash or Python scripts. These scripts were hard to share, version, or discover.

### The Solution
By introducing an Extension architecture, we are decoupling the **Core CLI** from **User-Space Logic**.
*   **Community velocity:** Users don't have to wait for an official CLI release to get new functionality.
*   **Developer Experience:** Developers can write extensions in their preferred language, add a manifest file, and share it immediately via a GitHub URL.

## 3. How-To Guide

Here is how you can use the new command to supercharge your terminal.

### Scenario A: Installing from GitHub
This is the most common use case—using a tool built by the community.

**Syntax:**
```bash
gemini extensions install <owner>/<repo>
# OR
gemini extensions install https://github.com/<owner>/<repo>
```

**Example:**
Imagine a community member created a "commit-fixer" extension.
```bash
gemini extensions install community-user/gemini-commit-fixer
```
*Output:*
> ✅ Installed extension: commit-fixer
> ℹ️  New command available: gemini commit-fixer

### Scenario B: Installing from Local Path (Sideloading)
This is essential for developers creating their own extensions or for teams using internal tools that aren't on public GitHub.

**Syntax:**
```bash
gemini extensions install <path-to-folder>
```

**Example:**
```bash
cd ~/my-projects/gemini-code-reviewer
gemini extensions install .
```
*Output:*
> 🔗 Linked local extension: code-reviewer
> ℹ️  New command available: gemini code-reviewer (Dev Mode)

## 4. Walkthrough / Technical Deep Dive

When you run `gemini extensions install`, the CLI performs a specific orchestration to ensure the extension is safe and valid. Here is what happens under the hood:

1.  **Resolution**:
    *   If the argument is a **URL/Repo**, the CLI uses the system's `git` binary to clone the repository into a hidden configuration directory (typically `~/.config/gemini/extensions`).
    *   If the argument is a **Path**, the CLI verifies the directory exists and creates a symlink to the extensions directory (allowing for live updates without re-installing).

2.  **Manifest Validation**:
    *   The CLI looks for a `gemini.extension.yml` (or `.json`) file in the root of the target.
    *   It parses the manifest to determine the **Binary Name** (the executable entry point) and the **Command Name** (how you call it in the CLI).

3.  **Dependency Handling**:
    *   *Note based on implementation:* If the extension requires compilation (Go/Rust) or dependencies (Node/Python), the installation script defined in the manifest (e.g., `make install` or `npm install`) is triggered within a sandboxed environment.

4.  **Registration**:
    *   The extension is added to the CLI's internal registry map. When you type `gemini <command>`, the CLI checks core commands first, then looks up the registry to delegate execution to the extension script.
