# 🚀 What's New: Voice Synthesis with Eleven Labs & Gemini CLI

## 1. Feature Summary
The Gemini CLI has expanded its multi-modal capabilities by introducing the **Eleven Labs Extension**. By installing this extension, developers can now instruct Gemini to generate high-quality text-to-speech (TTS) audio, manage voice settings, and play back audio tracks directly from the terminal.

This integration is built on the **Model Context Protocol (MCP)**, allowing Gemini to seamlessly interface with the Eleven Labs API as a native tool.

**Key Capabilities:**
*   **Text-to-Speech:** Convert text or file contents into spoken audio.
*   **Voice Management:** List and select specific voice IDs available in your Eleven Labs account.
*   **Playback Control:** Manage audio history and play generated tracks immediately.

---

## 2. Background & Context
*Based on the repository structure (`elevenlabs-mcp`) and standard CLI workflow optimizations.*

### Why this change?
Previously, working with AI voice generation required developers to context-switch between their IDE/Terminal and the Eleven Labs web dashboard, or write ad-hoc Python/cURL scripts to interact with the API.

### The Problem
*   **Friction:** Generating a quick audio sample for a project required leaving the command line.
*   **Disconnected Workflows:** Developers using Gemini for text generation (e.g., summarizing logs, writing copy) couldn't immediately verify how that text sounded without an external tool.

### The Solution
By wrapping the Eleven Labs API in an **MCP Server**, this extension allows the Gemini CLI to "understand" voice generation tools. It bridges the gap between text generation and audio synthesis. This aligns with the broader goal of making the Gemini CLI a central hub for multi-modal interactions, allowing users to pipeline text outputs directly into audio inputs without manual copy-pasting.

## 3. How-To Guide

Follow these steps to enable voice capabilities in your terminal.

### Prerequisites
*   Gemini CLI installed and authenticated.
*   An active [Eleven Labs API Key](https://elevenlabs.io/).

### Step 1: Install the Extension
Run the following command to pull the extension definition from the GitHub repository:

```bash
gemini extensions install https://github.com/elevenlabs/elevenlabs-mcp
```

### Step 2: Configuration
When prompted (or via environment variables), you will need to provide your Eleven Labs API key:
`ELEVENLABS_API_KEY=your_key_here`

### Step 3: Usage Examples

**Example A: Basic Text-to-Speech**
Ask Gemini to speak a simple phrase.
```bash
gemini "Say 'Hello world, my name is Gemini' using a standard American voice."
```

**Example B: Reading Files**
Pipeline a text file into audio.
```bash
gemini "Read the contents of README.md using the voice 'Rachel'."
```

**Example C: Managing Voices**
Ask Gemini to find available voices.
```bash
gemini "List all available Eleven Labs voices and tell me the ID for 'Adam'."
```

## 4. Walkthrough / Technical Deep Dive

### Under the Hood: The Model Context Protocol (MCP)
This feature isn't just a hardcoded command; it is an implementation of an **MCP Server**.

1.  **Tool Definitions:** When the extension is installed, the `elevenlabs-mcp` server exposes a set of JSON schemas to the Gemini CLI. These schemas define tools like `generate_audio`, `get_voices`, and `play_audio`.
2.  **Intent Recognition:** When you type a prompt (e.g., "Read this text"), Gemini analyzes the request. It recognizes that the intent matches the `generate_audio` tool definition provided by the extension.
3.  **Function Calling:** Gemini constructs a JSON payload containing the necessary arguments (the text to read, the voice ID) and sends it to the Extension.
4.  **API Execution:** The Extension makes the HTTP request to `api.elevenlabs.io`.
5.  **Binary Handling:** The Eleven Labs API returns an audio stream (MPEG/PCM). The extension handles the buffering and uses system audio libraries (like `ffplay` or native OS audio) to play the stream directly to the user's speakers.

### Architecture Diagram
`User Prompt` -> `Gemini CLI (MCP Host)` -> `Selects 'generate_audio' Tool` -> `Eleven Labs MCP Server` -> `Eleven Labs API` -> `Audio Output`
