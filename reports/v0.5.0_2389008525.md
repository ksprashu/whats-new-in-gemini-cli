# 🚀 What's New: Gemini CLI + Model Context Protocol (MCP) Integration

**Date:** October 26, 2023
**Focus:** Interoperability & Local Tooling
**Status:** Live

## 1. Feature Summary
The Gemini CLI has officially introduced support for the **Model Context Protocol (MCP)**, enabling seamless integration with `GoFastMCP`. This update transforms the Gemini CLI from a text-generation tool into an agentic interface capable of interacting with your local resources, databases, and internal APIs.

By connecting to an MCP server (such as one built with `GoFastMCP`), the Gemini CLI can now dynamically discover and execute tools, allowing developers to "chat" with their actual data and infrastructure directly from the terminal.

*   **Documentation:** [Get Started with Gemini CLI + GoFastMCP](https://gofastmcp.com/integrations/gemini-cli)

## 2. Background & Context
**The Problem:**
Previously, the Gemini CLI was sandboxed. While it had excellent reasoning capabilities, it lacked access to the developer's immediate context. To let Gemini interact with a local PostgreSQL database or read a specific file structure, developers had to manually copy-paste context or build complex, custom "function calling" wrappers for every single use case.

**The Solution:**
By adopting the **Model Context Protocol (MCP)** standard, we decouple the LLM client (Gemini CLI) from the tools.
*   **Standardization:** Instead of building a custom plugin for Gemini, developers can now build a standard MCP server.
*   **Ecosystem:** This update specifically highlights compatibility with `GoFastMCP`, a framework designed to spin up MCP servers instantly.

**Why this matters:**
This bridges the gap between "Generative AI" and "Agentic AI" in the terminal. It solves the context isolation problem by allowing the CLI to ask the MCP server: *"What tools do you have?"* and then use them on demand.

## 3. How-To Guide
Here is how to set up the Gemini CLI to talk to a local tool via `GoFastMCP`.

### Prerequisites
*   Latest version of Gemini CLI installed.
*   `npx` installed (for running GoFastMCP).

### Step 1: Create a Quick MCP Server
We will use `gofastmcp` to create a simple server that exposes a tool (e.g., adding numbers or reading a file).

```bash
# Create a new server directory
mkdir my-mcp-server
cd my-mcp-server

# Initialize a basic GoFastMCP server
npx create-gofastmcp@latest
```

### Step 2: Define a Tool
In your `index.ts` (or equivalent setup in the generated project), define a tool that Gemini can use.

```typescript
// Example: A tool to fetch system status
server.tool(
  "get_system_status",
  "Returns the current health status of the local system",
  {}, 
  async () => {
    return { content: [{ type: "text", text: "System is healthy. CPU: 12%." }] };
  }
);
```

### Step 3: Connect Gemini CLI to the Server
Run your MCP server, and then instruct the Gemini CLI to connect to it.

```bash
# Start your MCP server (usually runs on stdio or a local port)
npm start
```

*In a separate terminal window:*

```bash
# Run Gemini CLI pointing to the MCP configuration
gemini chat --mcp "node ./path/to/my-mcp-server/build/index.js"
```

### Step 4: Interact
Now, you can ask Gemini questions that require the tool.

**User:** "What is the current system status?"
**Gemini:** (Calls `get_system_status` tool silently) "The system is currently healthy with CPU usage at 12%."

## 4. Walkthrough / Technical Deep Dive
How does the Gemini CLI achieve this without hardcoded integrations?

1.  **Handshake & Discovery:**
    When you start the Gemini CLI with the `--mcp` flag, it spawns the specified MCP server as a subprocess (transport via Stdio). The CLI sends a JSON-RPC request: `tools/list`.

2.  **Schema Ingestion:**
    The `GoFastMCP` server responds with a JSON list of available tools and their input schemas (using JSON Schema).
    *   *Example:* It tells Gemini, "I have a tool called `get_weather` that requires a `city` string."

3.  **Context injection:**
    The Gemini CLI takes these tool definitions and injects them into the Gemini API call as **Function Declarations**.

4.  **The Execution Loop (Agentic Behavior):**
    *   **User Prompt:** "Check the weather in London."
    *   **LLM Decision:** Gemini (the model) recognizes it cannot answer this intrinsically. It returns a `function_call` stop sequence requesting `get_weather(city="London")`.
    *   **CLI Action:** The Gemini CLI intercepts this request. Instead of asking the user, it forwards the execution request to the `GoFastMCP` server via JSON-RPC.
    *   **Result:** The server executes the logic and returns the data.
    *   **Final Answer:** The CLI feeds the result back to Gemini, which generates the natural language response.
