# 🚀 Gemini CLI Feature Report: Input Undo/Redo

**Release Impact:** High Usability  
**Contributor:** @masiafrest  
**PR Reference:** [#4625](https://github.com/google-gemini/gemini-cli/pull/4625)

---

## 1. Feature Summary
The Gemini CLI interactive prompt now supports **Undo and Redo** operations. Users can effortlessly recover accidentally deleted text or revert unwanted edits while composing prompts within the CLI REPL environment. This update brings standard text editor capabilities—specifically `Ctrl+Z` and `Ctrl+Shift+Z`—directly into the terminal input experience.

## 2. Background & Context
**The Problem:**
As users leverage the Gemini CLI for increasingly complex tasks, the prompts they type have grown in length and complexity. Writing a multi-paragraph system instruction or a nuanced coding query directly in the terminal is high-stakes; a slip of the finger (like holding Backspace too long or an accidental kill-line command) previously meant losing the entire thought train.

**The Solution:**
Community feedback indicated a strong demand for safety mechanisms in the input field. As noted in the pull request discussions, maintainers highlighted that "a lot of users are asking for undo+redo."

This feature was implemented to bridge the gap between a raw shell input and a modern text editing experience, ensuring that users feel confident drafting long-form content directly in the Gemini CLI without needing to draft externally and paste it in.

## 3. How-To Guide

Using the new feature is intuitive for anyone familiar with standard text editing shortcuts.

### Prerequisites
Ensure you have updated the Gemini CLI to the latest version containing PR #4625.

### Step-by-Step
1.  **Launch the CLI:** Start the interactive mode by running `gemini repl` (or your standard entry command).
2.  **Type a Prompt:** Begin typing a sentence.
    > *Example input:* "Write a Python script to scrape a website."
3.  **Make a Mistake:** Delete the word "website".
    > *Current input:* "Write a Python script to scrape a "
4.  **Undo (`Ctrl+Z`):** Press `Ctrl + z`.
    > *Result:* The text reverts to "Write a Python script to scrape a website."
5.  **Redo (`Ctrl+Shift+Z`):** Press `Ctrl + Shift + z`.
    > *Result:* The text returns to the state after deletion: "Write a Python script to scrape a "

*Note: These shortcuts work specifically within the Gemini CLI input buffer, independent of your terminal emulator's native history.*

## 4. Walkthrough / Technical Deep Dive

The implementation of this feature required a shift in how the CLI handles input state. Rather than treating the input prompt as a volatile, current-state string, the underlying architecture was updated to utilize a **Text Buffer** system.

### The Role of `text-buffer.ts`
Based on the code review context, the core logic relies on a specialized module, likely named `text-buffer.ts`.

1.  **State Snapshots:** Instead of just storing the current string, `text-buffer.ts` maintains a history stack (a list of previous states) and a future stack (for redo operations).
2.  **Snapshot Triggers:** Every time the user pauses typing or performs a destructive action (like a delete or paste), the buffer captures the state of the input before the change.
3.  **Pointer Management:**
    *   **Undo:** Moves the state pointer backward in the stack and renders that string to the terminal output.
    *   **Redo:** Moves the state pointer forward, restoring the previously undone change.
4.  **Terminal Rendering:** The update ensures that when the state changes via shortcut, the terminal line is cleared and repainted with the correct buffer content instantly, providing a seamless visual experience.

This approach separates the input management logic from the main application loop, making the CLI more robust and easier to extend with future text-manipulation features.
