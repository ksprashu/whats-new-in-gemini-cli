# What’s New: Introducing the `/prompt-suggest` Slash Command

**PR:** [#17264](https://github.com/google-gemini/gemini-cli/pull/17264) | **Author:** @NTaylorMullen

## 1. Feature Summary
We are excited to introduce a new productivity booster for the Gemini CLI: the **/prompt-suggest** slash command. This feature acts as an integrated "meta-prompter," allowing developers to input a vague concept or a short topic and instantly receive high-quality, structured prompt suggestions. It is designed to bridge the gap between user intent and the specific phrasing required to get the best output from the Large Language Model (LLM).

## 2. Background & Context
**The Problem:**
One of the most common friction points in working with LLMs via the command line is "Blank Page Syndrome" or "Prompt Fatigue." Users often know *what* they want (e.g., "write unit tests") but may not frame the request with enough context or specificity to get a usable result on the first try. This leads to a frustrating loop of vague inputs and mediocre outputs.

**The Solution:**
Based on the implementation in PR #17264, this feature introduces a utility specifically designed to unblock the user. By invoking `/prompt-suggest`, the CLI shifts from "Chat Mode" to "Utility Mode." Instead of trying to answer the user's vague query, the CLI leverages Gemini to act as an Expert Prompt Engineer, analyzing the input and returning optimized prompt variations.

**Why this matters:**
*   **Reduced Context Switching:** You no longer need to tab out to a browser to look up prompt templates.
*   **Education:** It implicitly teaches users how to structure better prompts by showing them high-quality examples based on their own ideas.

## 3. How-To Guide

Using the feature is straightforward and integrated directly into the standard REPL loop.

### Basic Usage
1.  Open your terminal and start the Gemini CLI.
2.  Type `/prompt-suggest` followed by a topic or a rough draft of your idea.

**Example 1: Coding**
```bash
> /prompt-suggest create a react button component
```

**Output:**
Gemini might return suggestions such as:
1.  *"Create a reusable React Button component using TypeScript and Tailwind CSS, including variants for primary, secondary, and ghost styles."*
2.  *"Write a React Button component with built-in accessibility features (ARIA labels) and support for an 'isLoading' state."*

### Selection
Once the suggestions are displayed, you can typically copy the one that best fits your needs, paste it into the prompt line, and execute it to generate your actual code.

## 4. Walkthrough / Technical Deep Dive
*Based on standard slash-command architectures in the Gemini CLI ecosystem.*

Under the hood, this feature leverages a "Meta-Prompting" architecture. When the CLI parser detects the forward slash `/`, it intercepts the message before it is sent as a standard chat message.

1.  **Command Parsing:** The CLI identifies `prompt-suggest` as a registered command handler.
2.  **Payload Extraction:** The text following the command (e.g., "create a react button") is extracted as the `user_intent`.
3.  **The Meta-Prompt:** The CLI constructs a specialized system prompt, invisible to the user. It likely looks something like this:
    > "You are an expert prompt engineer. The user has provided the following topic: '{user_intent}'. Generate 3 distinct, high-quality, and detailed prompts that the user could send to an LLM to achieve specific results related to this topic."
4.  **Execution:** This meta-prompt is sent to the Gemini API.
5.  **Rendering:** The response is formatted (likely purely text or markdown) and printed to the standard output, bypassing the chat history memory so that the *suggestion process* doesn't pollute the context of your actual conversation.
