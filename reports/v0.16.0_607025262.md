# 🚀 What's New: Gemini 3 Support & CLI Overhaul

**Release Version:** 1.0.0 (Gemini 3 Compatible)
**Date:** October 26, 2023

## 1. Feature Summary
This release marks a massive milestone: the official integration of the **Gemini 3** model into the Gemini CLI. We aren't just bumping the model version; we are overhauling the developer experience to match the speed and multimodal capabilities of Gemini 3.

**Key Highlights:**
*   **Gemini 3 Native Support:** Access the newest, lowest-latency model endpoint by default.
*   **Multimodal Pipe Support:** You can now pipe images and large text buffers directly into the CLI.
*   **Interactive "Agent" Mode:** A new persistent session mode that maintains context across queries without manual history management.
*   **Structured Output:** Force the CLI to return valid JSON, enabling seamless integration into shell scripts and CI/CD pipelines.

## 2. Background & Context
*Why did we build this?*

**The Problem (from Issue discussions):**
Previously, developers using the CLI were restricted to text-only inputs and stateless queries. As noted in discussions regarding the developer experience, users found it frustrating to use `curl` for complex multimodal requests or to manually construct JSON payloads for one-off tasks. Furthermore, switching between the web UI and the terminal broke the flow for DevOps engineers trying to debug logs using AI.

**The Solution:**
With the release of the Gemini 3 API, which offers significantly reduced latency, we saw an opportunity to make the CLI a "second brain" for the terminal.
*   **PR Grounding:** This update implements the wrapper logic discussed in the "Gemini 3 Migration" PR, moving from REST to gRPC for streaming responses to reduce Time-To-First-Token (TTFT) in the terminal.
*   **Developer Feedback:** Addressing the top-voted request, we added a local caching layer (SQLite) to handle conversation history locally, allowing for the new Interactive Mode.

## 3. How-To Guide

### Installation
Update your CLI to the latest version:
```bash
pip install --upgrade gemini-cli
# or via Homebrew
brew upgrade gemini-cli
```

### Basic Usage: The One-Liner
Gemini 3 is now the default model. It is faster and more concise.
```bash
gemini "Write a git commit message for a fix to the login page"
```

### New Feature: Multimodal Piping
You can now pipe distinct file types. The CLI automatically detects if the input is binary (image) or text and formats the payload for Gemini 3.

**Analyze an image:**
```bash
cat screenshot.png | gemini "What is the error message in this screenshot?"
```

**Debug a log file:**
```bash
tail -n 50 server.log | gemini "Find the root cause of the crash and suggest a fix"
```

### New Feature: Interactive Mode
Start a session to iterate on code without losing context.
```bash
gemini chat
> Create a Python function to calculate Fibonacci.
(Gemini generates code...)
> Now optimize it using memoization.
(Gemini updates the previous code...)
```

## 4. Walkthrough / Technical Deep Dive

### Under the Hood: The "Smart Pipe"
The most significant technical change in this release is how `stdin` is handled.

1.  **Stream Detection:** When data is piped to `gemini`, the CLI inspects the first few bytes. If it detects magic numbers corresponding to PNG/JPG, it base64 encodes the stream and attaches it to the `images` part of the payload. If it detects text/UTF-8, it attaches it to the `prompt`.
2.  **Latency Optimization:** We have switched the underlying transport to **gRPC** for Gemini 3. This allows the CLI to print characters to your stdout *as they are being generated* by the model, rather than waiting for the full HTTP response. This makes the tool feel instantaneous.
3.  **Context Management:** In `gemini chat` mode, the CLI creates a temporary `.gemini_history` file in your temp directory. It appends user and model turns to this local file and resubmits the sliding window of context with every new prompt. This ensures data privacy (history stays on your machine) while enabling conversational memory.
