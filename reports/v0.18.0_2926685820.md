# What’s New in Gemini CLI: Google Workspace Integration

**Date:** November 20, 2025
**Version:** Extension Release `v1.0.0`
**Topic:** Google Workspace Extension

## 1. Feature Summary
The Gemini CLI has officially bridged the gap between your terminal and your office suite. With the new **Google Workspace Extension**, developers can now interact directly with Google Docs, Slides, Sheets, Gmail, and Chat without leaving the command line.

This feature allows users to install a verified extension module that wraps the Workspace APIs, enabling you to generate slide decks from code comments, query spreadsheets using natural language, draft design documents, and triage emails—all piped directly through standard `stdin/stdout` workflows or conversational interactive modes.

## 2. Background & Context
**Why was this change made?**
Developers often suffer from "context switching fatigue." Moving from a coding environment (IDE/Terminal) to a browser to update a tracker in Sheets, write a spec in Docs, or check an email disrupts the "flow state."

Based on the changelog and the guiding philosophy titled *"Bringing the office to the terminal,"* this extension solves three specific problems:
1.  **Friction:** Eliminates the need to open a GUI for text-based or data-heavy administrative tasks.
2.  **Automation:** Enables shell scripting of office tasks (e.g., `cat results.json | gemini workspace sheets update`).
3.  **Context Awareness:** Allows the Gemini CLI to "see" your organizational data (calendars, specs, budgets) to provide better coding answers.

## 3. How-To Guide

### Installation
To get started, you need to install the extension from the official repository.

```bash
gemini extensions install https://github.com/gemini-cli-extensions/workspace
```

*Note: Upon first run, this command will trigger an OAuth browser flow to grant the CLI permissions to access your Google Drive/Workspace account.*

### Usage Examples

**1. "Get your Calc on" (Sheets Integration)**
Pipe the contents of a spreadsheet directly into Gemini to analyze data without exporting to CSV.

```bash
# Analyze a specific sheet
gemini workspace sheets query --file "Q4 Budget" --prompt "What is the row with the highest AWS spend?"
```

**2. Writing Documentation**
Draft a requirement doc based on a local README file.

```bash
cat README.md | gemini workspace docs create --title "Project Specification" --prompt "Turn this technical readme into a product requirement doc"
```

**3. Building Slides**
Generate a presentation skeleton based on a prompt.

```bash
gemini workspace slides generate --topic "Q4 Engineering Roadmap" --slides 5
```

**4. Chat & Communication**
Check unread emails from a specific sender and summarize them.

```bash
gemini workspace gmail list --unread --from "manager@company.com" | gemini chat "Summarize these emails into a todo list"
```

## 4. Walkthrough / Technical Deep Dive
Under the hood, this feature leverages the new **Gemini CLI Extensions API**, which facilitates secure communication between the CLI binary and external APIs.

*   **Authentication:** The extension utilizes the Google Cloud SDK credential flow. It reuses the localized `gcloud` auth tokens if available, or initiates a scoped OAuth 2.0 flow specifically for `drive.file`, `gmail.readonly`, and other relevant scopes.
*   **Data Transformation:**
    *   **Input:** When you execute a command like `sheets query`, the extension fetches the raw cell data via the Sheets API.
    *   **Sanitization:** The extension parses the JSON response into a Markdown table format (or CSV text), which is the optimal format for the Gemini LLM context window.
    *   **Inference:** This structured text is passed to the Gemini model along with your prompt (e.g., "Find the sum of column B").
*   **Output:** The CLI renders the response back to `stdout`. For creation tasks (like making a Slide deck), the CLI sends structured JSON commands back to the Workspace API to instantiate the file.
