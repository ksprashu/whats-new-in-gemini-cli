# 🚀 What's New: MySQL Extension for Gemini CLI

**Date:** October 26, 2023
**Component:** Extensions / Database
**Status:** Released

## 1. Feature Summary

We are excited to announce the release of the **MySQL Extension** for the Gemini CLI. This new module bridges the gap between your terminal and your data, allowing developers to interact with MySQL databases using natural language.

Instead of manually crafting complex `JOIN` statements or context-switching to a GUI client, you can now ask Gemini to "Show me the top 10 users by spending," and the CLI will generate the SQL, execute it (upon approval), and display the results directly in your terminal.

## 2. Background & Context

### The Problem
Developers often spend significant time writing boilerplate SQL queries for ad-hoc data analysis. Context switching between the code editor, the terminal, and database clients (like Workbench or DBeaver) breaks flow. furthermore, when onboarding to a new codebase, understanding the database schema relationships can be daunting without documentation.

### The Solution
Based on community requests for better data integration, we created a modular extension system. The MySQL extension was prioritized to solve three key issues discussed in the development threads:
1.  **Schema Awareness:** The CLI needs to "see" the database structure to write accurate SQL.
2.  **Safety First:** Users wanted to ensure the LLM doesn't accidentally drop tables; we've implemented a "Human-in-the-loop" execution flow.
3.  **Frictionless Analysis:** Enabling quick insights without leaving the command line environment.

## 3. How-To Guide

### Prerequisites
*   Gemini CLI installed and authenticated.
*   Access to a running MySQL instance.

### Step 1: Install the Extension
First, enable the MySQL capability within the CLI.

```bash
gemini extension install mysql
```

### Step 2: Configure the Connection
You can set up a persistent connection profile or pass connection strings at runtime.

```bash
# Interactive setup
gemini mysql configure --name=prod_db
# Follow the prompts for Host, User, Password, and Database Name
```

### Step 3: Querying Your Data
Now, simply state what you need.

**Example 1: Basic Retrieval**
```bash
gemini mysql query --db=prod_db "List all customers who signed up in the last 7 days"
```

**Example 2: Complex Aggregation**
```bash
gemini mysql query --db=prod_db "Calculate the average order value grouped by region for 2023"
```

### Step 4: The Approval Flow
Gemini will output the generated SQL and ask for confirmation:

```text
> Gemini generated the following SQL:
  SELECT region, AVG(total_amount) 
  FROM orders 
  WHERE YEAR(created_at) = 2023 
  GROUP BY region;

> Execute this query? (y/N)
```

## 4. Walkthrough / Technical Deep Dive

Here is what happens under the hood when you run a command:

1.  **Schema Extraction (Context Windowing):**
    When the command initiates, the extension connects to the MySQL instance and queries the `information_schema`. It retrieves table names and column definitions relevant to your request. It does *not* read the actual data rows at this stage to preserve privacy and token limits.

2.  **Prompt Engineering:**
    The CLI constructs a system prompt containing:
    *   Your natural language question.
    *   The DDL (Data Definition Language) of your schema.
    *   Specific instructions to use MySQL-compatible syntax (e.g., using backticks or specific date functions).

3.  **LLM Generation:**
    Gemini analyzes the relationship between your intent and the table structure to generate a valid SQL query.

4.  **Review & Execution:**
    The SQL is presented to the user. Once confirmed, the extension utilizes the underlying MySQL driver to execute the query.

5.  **Output Rendering:**
    The results are fetched and rendered into a markdown table or JSON (depending on flags) directly in standard output.
