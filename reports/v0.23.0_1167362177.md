# 🚀 What's New: Windows Clipboard Image Support

**PR:** [#13997](https://github.com/google-gemini/gemini-cli/pull/13997) | **Contributor:** @sgeraldes

## 1. Feature Summary
We are excited to announce a significant quality-of-life improvement for our Windows user base. With the latest update, the Gemini CLI now supports **direct image pasting from the system clipboard**.

Instead of manually saving files and typing out file paths, Windows users can now simply press **`Alt+V`** to inject image data directly from their clipboard into the CLI prompt for multimodal analysis.

## 2. Background & Context
### The Problem
Prior to this update, utilizing Gemini’s multimodal capabilities (vision) in a CLI environment was high-friction. Users typically had to:
1.  Take a screenshot or download an image.
2.  Save it to a specific directory.
3.  Type a command flag (e.g., `--image`) followed by the absolute or relative path to that file.

This context-switching breaks the "flow state" developers rely on when working in the terminal.

### The Solution
Contributor **@sgeraldes** identified this friction point and implemented a direct bridge between the Windows Clipboard API and the CLI input buffer. By mapping the specific keybind `Alt+V`, the CLI can now detect image data in the clipboard and attach it to the current session context instantly.

## 3. How-To Guide
Here is how to utilize the new clipboard feature on Windows:

**Prerequisites:**
*   Windows OS (10 or 11)
*   Gemini CLI installed and updated

**Step-by-Step:**
1.  **Capture or Copy:** Use the Windows Snipping Tool (`Win + Shift + S`) to take a screenshot, or right-click an image in your browser/file explorer and select "Copy."
2.  **Open CLI:** Launch the Gemini CLI in your terminal of choice (PowerShell, Command Prompt, or Windows Terminal).
3.  **Paste:** Instead of `Ctrl+V` (which pastes text), press **`Alt+V`**.
4.  **Verify:** The CLI should indicate that an image has been attached (e.g., `<Image Attached>` or a similar indicator).
5.  **Prompt:** Type your question regarding the image (e.g., "Explain this architecture diagram") and hit Enter.
