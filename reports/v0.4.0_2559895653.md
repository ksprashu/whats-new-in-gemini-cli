# 🚀 What's New: Introducing Smart Edit

**Release Status:** Experimental (Opt-in)
**Contributor:** @silviojr

## 1. Feature Summary
A new, experimental editing capability dubbed **"Smart Edit"** has been introduced to the Gemini CLI Core. This feature provides an alternative mechanism for the AI to apply code changes to your files. It is currently hidden behind a feature flag, allowing adventurous users to test its stability and improved accuracy before it becomes the default behavior.

## 2. Background & Context
Applying code edits generated by Large Language Models (LLMs) is notoriously difficult. Standard "search and replace" blocks often fail if the LLM hallucinates slightly wrong indentation, misses a line of context, or creates a diff that doesn't perfectly match the user's local file state.

While the specific PR discussion text was not provided, the file structure in the coverage report points to a significant architectural addition. The presence of `src/tools/smart-edit.ts` alongside the existing `src/tools/edit.ts` suggests this is a complete overhaul or alternative strategy for the editing logic, likely designed to be more robust (or "smart") when locating where code should be inserted or modified.

## 3. How-To Guide
To enable this feature, you must manually update your configuration file.

### Step 1: Locate or Create `settings.json`
If you haven't configured the CLI manually before, you may need to find your configuration directory (usually `~/.config/gemini-cli/` or similar depending on your OS).

### Step 2: Enable the Flag
Add the following key-value pair to your `settings.json`:

```json
{
  "useSmartEdit": true
}
```

### Step 3: Use the CLI as Normal
Restart the Gemini CLI. You do not need to issue special commands; the CLI will automatically route editing requests through the new `SmartEdit` tool logic instead of the standard editor.
