# 🚀 What's New: The Gemini CLI Developer Portal

## 1. Feature Summary
We are excited to announce a major overhaul of the developer experience with the launch of the **Gemini CLI Home Page**. This release transitions our documentation from a standard repository README structure to a fully-featured, centralized developer portal. The new site is designed to be the single source of truth, featuring revamped **Getting Started** workflows, comprehensive **API/Command References**, and a dedicated catalog for **Extensions**.

## 2. Background & Context
**The Problem:**
As the Gemini CLI ecosystem grew, developers frequently reported friction in three key areas (based on common repository feedback):
1.  **Onboarding Friction:** New users found it difficult to move from installation to their first successful prompt using only the GitHub README.
2.  **Discoverability:** Advanced flags and configuration options were buried in source code or lengthy markdown files, making them hard to search.
3.  **Ecosystem Fragmentation:** Community extensions and plugins existed but lacked a centralized directory, limiting their adoption.

**The Solution:**
This new home page addresses these issues by decoupling documentation from the codebase. By introducing a dedicated documentation engine, we provide:
*   **Structured Learning Paths:** Distinct separation between tutorials and reference material.
*   **Searchability:** A dedicated search index for commands, flags, and error codes.
*   **Ecosystem Visibility:** A spotlight section for Extensions to encourage community contribution and usage.

## 3. How-To Guide
Here is how to maximize your productivity with the new resources:

### A. Accelerate Onboarding
If you are new to the tool or setting up a fresh environment:
1.  Navigate to the **"Getting Started"** tab on the new home page.
2.  Select your OS (Windows, macOS, Linux) for specific installation scripts.
3.  Follow the **"5-Minute Quickstart"** to configure your API keys and run your first query.

### B. Utilizing the Reference Docs
Stop guessing flags. When writing complex scripts:
1.  Go to the **Reference** section.
2.  Use the sidebar to locate specific commands (e.g., `gemini chat`, `gemini generate`).
3.  View the interactive parameter tables which now define required vs. optional flags, default values, and data types.

### C. Exploring Extensions
To extend the CLI's capabilities:
1.  Visit the **Extensions** catalog.
2.  Browse tailored plugins for workflow integration (e.g., IDE formatting, CI/CD pipes).
3.  Follow the installation instructions provided for each specific extension.
