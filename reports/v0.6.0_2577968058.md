# 🚀 Gemini CLI Update: Natural Language Interaction with PostgreSQL

**Date:** October 26, 2023
**Feature:** PostgreSQL Extension
**Status:** Available in v1.x

---

## 1. Feature Summary
The Gemini CLI now includes a dedicated **Postgres Extension**. This feature allows developers to connect the CLI directly to a PostgreSQL database and interact with their data using natural language.

Instead of writing complex SQL queries manually or context-switching to GUI tools (like pgAdmin or DBeaver), users can now ask questions like *"Show me the top 5 users by signup date"* directly in their terminal and receive both the generated SQL and the query results.

---

## 2. Background & Context
**Why was this change made?**
Based on developer feedback and issue tracking, two main friction points were identified in the previous workflow:
1.  **Context Switching:** Developers working in the CLI often need to verify data states. Leaving the terminal to open a database client breaks flow.
2.  **Schema Fatigue:** On large legacy databases, remembering exact table names and column relationships is difficult. Developers were pasting schemas into web-based LLMs to get SQL help.

**The Solution**
This extension bridges that gap by bringing the schema context directly to the Gemini model. The PRs focused on building a safe, read-optimized bridge that fetches the `information_schema`, allows the LLM to construct the query, and executes it within the CLI environment.

## 3. How-To Guide

### Prerequisites
*   Gemini CLI installed and authenticated.
*   A running PostgreSQL instance.
*   A read-only database user (recommended for safety).

### Step 1: Install the Extension
Update your CLI and install the postgres module:
```bash
gemini extension install postgres
```

### Step 2: Connect to your Database
You can pass the connection string via a flag or set it as an environment variable `POSTGRES_CONNECTION_STRING`.

```bash
export POSTGRES_CONNECTION_STRING="postgresql://user:password@localhost:5432/mydb"
```

### Step 3: Run Natural Language Queries
Use the `postgres` command followed by your question in quotes.

**Example 1: Simple Retrieval**
```bash
gemini postgres "List all customers who signed up in the last 7 days"
```

**Example 2: Aggregations**
```bash
gemini postgres "What is the average order value for the 'Electronics' category?"
```

**Output:**
The CLI will display:
1.  The SQL generated.
2.  A confirmation prompt (optional, configurable).
3.  The resulting data table.

## 4. Walkthrough / Technical Deep Dive
Here is how the extension processes your request "under the hood":

1.  **Schema Introspection:**
    When the command runs, the CLI queries the PostgreSQL `information_schema`. It retrieves table names, column names, and data types. It does *not* retrieve the actual row data at this stage to preserve privacy and reduce token usage.
2.  **Prompt Engineering:**
    The CLI constructs a prompt containing:
    *   The user's natural language question.
    *   The condensed schema definition.
    *   System instructions (e.g., "Only generate SQL," "Use PostgreSQL syntax").
3.  **Model Inference:**
    This payload is sent to Gemini. The model uses its coding capabilities to map the natural language intent to the provided schema relations (e.g., knowing to `JOIN` the `users` and `orders` tables).
4.  **Execution & Safety:**
    The CLI receives the raw SQL.
    *   *Safety Check:* The extension parses the SQL to ensure it is a `SELECT` statement (preventing accidental `DROP` or `DELETE` commands).
    *   The query is executed against the DB.
5.  **Presentation:**
    The results are formatted into a terminal-friendly Markdown table or JSON, depending on user preference.
