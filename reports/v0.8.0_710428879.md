# 🚀 What's New: The Gemini CLI Documentation Hub

**Date:** October 26, 2023
**Topic:** Documentation & Ecosystem Launch

## 1. Feature Summary
We are thrilled to announce a major milestone for the Gemini CLI ecosystem: **The launch of our dedicated landing page and documentation hub.**

Moving beyond simple README files, the project now lives at **[geminicli.com](https://geminicli.com)**. This new portal serves as the central source of truth for the CLI, featuring a completely restructured "Getting Started" guide, comprehensive API/flag references, and a brand-new catalog for discovering community Extensions.

## 2. Background & Context
**Why was this change made?**
As the Gemini CLI capabilities grew, relying solely on GitHub `README.md` files became insufficient for our user base. We identified several friction points that necessitated a dedicated documentation site:

*   **Onboarding Friction:** New users found it difficult to piece together installation and configuration steps scattered across repository files.
*   **Discoverability:** Advanced features and flags were often buried in code comments or obscure release notes, making them hard to find for power users.
*   **Ecosystem Fragmentation:** With the introduction of Extensions, there was no centralized place to showcase community contributions. Users had to rely on word-of-mouth or searching GitHub topics to find plugins.

**The Solution:**
We built `geminicli.com` to solve these specific information architecture problems. By separating "Tutorials" from "References" and creating a dedicated "Extensions" marketplace view, we aim to lower the barrier to entry for new developers while giving power users quick access to technical details.
