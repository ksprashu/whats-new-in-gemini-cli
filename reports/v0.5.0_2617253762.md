# 🚀 What’s New: Seamless Positional Prompts for Gemini CLI

## 1. Feature Summary
The Gemini CLI has significantly improved its developer ergonomics with the introduction of **Positional Prompts**.

Previously, running a quick, non-interactive query required the `-p` flag. With this update, the CLI now interprets the first positional argument as a prompt. This means you can now invoke Gemini headlessly by simply typing `gemini "Your prompt here"`, bypassing the interactive REPL entirely.

## 2. Background & Context
**Why was this change made?**
In the world of command-line interfaces, speed and "pipeability" are paramount. Users frequently want to use Gemini for single-shot tasks—like generating a git commit message, explaining a code snippet, or converting a data format—without entering a persistent chat session.

*   **The Friction:** Previously, users had to type `gemini -p "prompt"`. While effective, the `-p` flag felt redundant for the most common use case of a CLI: running a command and getting an output.
*   **The Solution:** Addressed in **PR #7668** (by contributor @allenhutchison) and linked to **Issue #6706**, this change aligns the Gemini CLI with standard Unix utilities (like `echo` or `mkdir`), where the primary input is provided directly after the command name.
*   **Goal:** To reduce keystrokes and make the CLI more intuitive for scripting and automation workflows.

## 3. How-To Guide

Here is how you can leverage the new positional arguments.

### Basic Usage
**Old Way:**
```bash
gemini -p "Write a haiku about TypeScript"
```

**New Way:**
```bash
gemini "Write a haiku about TypeScript"
```

### Scripting and Piping
This feature shines when chaining commands. Since positional arguments behave synonymously with the `-p` flag (non-interactive mode), the output is printed directly to `stdout`.

**Example: Generate a Git Commit Message**
```bash
git diff | gemini "Write a concise commit message based on these changes"
```

**Example: Quick Code Explanation**
```bash
cat complex_logic.ts | gemini "Explain what this code does in one sentence"
```

### Handling Multiple Words
Always remember to use quotes if your prompt contains spaces to ensure the shell treats it as a single argument.

```bash
# Correct
gemini "How do I reverse a binary tree?"

# Incorrect (might only capture "How" depending on shell expansion)
gemini How do I reverse a binary tree?
```

## 4. Walkthrough / Technical Deep Dive

### Under the Hood
The change affects the entry point of the application (`src/gemini.tsx`) and the argument parsing logic in `src/interactiveCli.ts`.

1.  **Argument Parsing:** When the CLI initializes, it inspects `process.argv`.
2.  **Command Detection:** The CLI checks if the first argument matches a known internal command (e.g., `config`, `auth`, `context`).
3.  **Fallthrough Logic:** If the argument is *not* a known command (and not a flag like `--version`), the CLI now assumes it is a prompt string.
4.  **Headless Execution:** Instead of booting the full React-based UI (Ink) used for the interactive session, the CLI treats this input exactly as if it were passed via the `--prompt` (`-p`) flag.
5.  **Lifecycle:**
    *   The prompt is sent to the model.
    *   The response streams to `stdout`.
    *   The process exits with code `0` immediately after generation is complete.
