# 🚀 What's New: Data Commons Extension for Gemini CLI

**Date:** October 26, 2023
**Feature:** Data Commons Integration
**Status:** Available Now

---

## 1. Feature Summary
We are thrilled to announce the release of the **Data Commons extension** for the Gemini CLI. This new extension bridges the gap between Gemini’s generative capabilities and massive real-world public datasets.

By installing this extension, developers can enable the Gemini CLI to "ground" its responses in statistical fact. Instead of relying solely on the model's training data (which cuts off at a specific date), the CLI can now query the [Data Commons](https://datacommons.org/) knowledge graph in real-time to fetch accurate data regarding demographics, economics, climate, and health across the globe.

---

## 2. Background & Context
*Why did we build this?*

One of the most persistent challenges in working with Large Language Models (LLMs) is **hallucination regarding specific statistics**. While LLMs are excellent at reasoning and coding, they are not reliable databases. If you ask a standard model for "The population of Kyoto in 2018," it might guess based on probability rather than fact.

Based on community feedback and recent Pull Requests, the goal was to implement a **Tool Use (Function Calling)** pattern. We wanted to move away from the user having to manually fetch CSVs and paste them into the context window.

This extension solves three specific problems:
1.  **Accuracy:** It fetches ground-truth data from reputable sources (World Bank, CDC, Census Bureau) aggregated by Data Commons.
2.  **Freshness:** It accesses the latest available data in the Knowledge Graph, extending beyond the model's training cutoff.
3.  **Ease of Use:** It creates a natural language interface for complex statistical queries, removing the need for users to learn the specific Data Commons API or SPARQL syntax.

## 3. How-To Guide

Getting started with the Data Commons extension is straightforward.

### Step 1: Installation
Install the extension directly from the official repository using the `extensions install` command:

```bash
gemini extensions install https://github.com/gemini-cli-extensions/datacommons
```

### Step 2: Verifying Installation
Ensure the extension is active (it should appear in your list of installed tools):

```bash
gemini extensions list
```

### Step 3: Usage Examples
Once installed, Gemini will automatically detect when a prompt requires a data lookup. You do not need to use a specific prefix command; just ask natural questions.

**Example A: Simple Demographics**
```bash
gemini "What is the population of Brazil compared to Nigeria?"
```

**Example B: Economic Data**
```bash
gemini "Show me the GDP growth trend of South Korea over the last 5 years available."
```

**Example C: Complex Correlation (Grounding)**
```bash
gemini "Is there a correlation between CO2 emissions and life expectancy in Europe? Use data to support your answer."
```

## 4. Walkthrough / Technical Deep Dive
*How does it work under the hood?*

This feature leverages **Gemini’s Function Calling capabilities**. Here is the lifecycle of a Data Commons request within the CLI:

1.  **Tool Definition:** When the extension is loaded, it registers a "tool" definition with the Gemini API. This definition describes the Data Commons API schema (e.g., `get_stat_value(place, variable)`).
2.  **Intent Recognition:** When you type *“What is the unemployment rate in California?”*, the Gemini model analyzes the prompt and determines that it cannot answer accurately from internal memory. It recognizes that the `datacommons` tool matches the intent.
3.  **Parameter Extraction:** The model extracts the necessary variables—converting "California" into a DCID (Data Commons Identifier like `geoId/06`) and "unemployment rate" into the statistical variable (e.g., `UnemploymentRate_Person`).
4.  **API Execution:** The CLI intercepts this function call request, executes the HTTP request against the Data Commons REST API, and captures the JSON response.
5.  **Synthesis:** The raw statistical data (JSON) is fed back into the Gemini context window. Gemini then parses this data to generate a human-readable, conversational response, citing the numbers returned by the API.
