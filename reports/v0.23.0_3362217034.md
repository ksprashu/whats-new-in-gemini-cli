# 🚀 Feature Report: Gemini CLI Wrapped

## 1. Feature Summary
We are thrilled to introduce **Gemini CLI Wrapped**—a fun, data-driven visualization tool designed to give you insights into your AI-assisted development journey.

By running a simple command, developers can now generate a retrospective summary of their interactions with the Gemini CLI. This feature analyzes local usage history to display statistics such as your most used models (e.g., Gemini 1.5 Pro vs. Flash), your top programming languages generated, token usage trends, and activity streaks. It brings the popular "Year in Review" concept directly to your terminal.

## 2. Background & Context
**Why was this change made?**
As developers integrate AI tools more deeply into their daily workflows, the Gemini CLI has become a silent partner in thousands of commits. However, users lacked visibility into their own usage patterns.

Based on community feedback and the desire to increase engagement, we identified two key motivations for this feature:
1.  **Quantified Self for Devs:** Users wanted to know, *"Am I using Gemini mostly for debugging Python or scaffolding React components?"* or *"Which model is my daily driver?"*
2.  **Community Fun:** Inspired by the viral nature of "Spotify Wrapped," this feature aims to turn utility into a shareable moment. It allows developers to celebrate their productivity and share their "AI personality" with the community.

## 3. How-To Guide
Getting your usage stats is incredibly simple. You do not need to update your main global configuration to run this, as it utilizes `npx` to fetch the latest visualization script.

**Prerequisites:**
*   You must have used the Gemini CLI previously (so there is a history log to analyze).

**Instructions:**

1.  Open your terminal.
2.  Run the following command:
    ```bash
    npx gemini-wrapped
    ```
3.  The CLI will parse your local history and render a visual dashboard in your terminal containing:
    *   Total conversations initiated.
    *   **Top Model:** Your most frequently used Gemini variant.
    *   **Top Languages:** A breakdown of code snippets generated (e.g., TypeScript, Python, Go).
    *   **Busiest Day:** The day of the week you interact with Gemini the most.

4.  (Optional) Take a screenshot of your terminal output to share on social media!

## 4. Walkthrough / Technical Deep Dive
How does `npx gemini-wrapped` turn text logs into insights? Here is a look under the hood:

### Data Source: Local History
The Gemini CLI maintains a local history file (typically stored in `~/.config/gemini/history.json` or a local SQLite database). This ensures that your usage data remains private and local to your machine; `gemini-wrapped` does **not** send this data to a remote server for processing.

### The Analysis Pipeline
When the command is executed, the script performs the following logic:

1.  **Ingestion:** It streams the history file, filtering for valid request/response pairs.
2.  **Model Aggregation:** It parses the metadata of each request to tally counts for specific models (e.g., `gemini-1.5-flash`, `gemini-1.0-pro`).
3.  **Language Detection:** The most complex part of the script analyzes the Markdown code blocks in Gemini's *responses*.
    *   It scans for triple backticks (```) followed by a language identifier (e.g., ```rust).
    *   It aggregates these identifiers to determine your "Top Languages."
4.  **Temporal Analysis:** It utilizes timestamps to calculate usage streaks and identify peak coding hours.

### Visualization (TUI)
The output utilizes Terminal UI libraries (likely `ink` or `chalk` with `cli-charts`) to render ANSI-colored bar charts and stylized text directly in the console, ensuring a high-fidelity experience without needing to open a web browser.
