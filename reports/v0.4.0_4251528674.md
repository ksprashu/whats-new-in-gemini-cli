# 🚀 What's New: Source Citations in Gemini CLI

**Release Reference:** PR #7350 (Contribution by @scidomino)

## 1. Feature Summary
Transparency regarding the origin of AI-generated code and information is critical for developers. The Gemini CLI has introduced a **Citations** feature.

*   **For Enterprise Code Assist Users:** Citations are now **enabled by default**. When the model generates code or answers based on specific documentation or repositories, it will explicitly cite the source.
*   **For All Other Users:** You can manually enable this feature to see where Gemini is sourcing its information.

## 2. Background & Context
Generative AI models are powerful, but "hallucinations" (confident but incorrect answers) and "provenance" (where did this code come from?) are major concerns, particularly in professional and enterprise environments.

*   **Trust & Verification:** Developers need to verify that the code provided by the CLI follows best practices or comes from official documentation.
*   **IP & Compliance:** Enterprise users often require strict adherence to licensing. Knowing if a snippet of code comes from a specific open-source repository or official documentation helps in maintaining license compliance.
*   **The Solution:** By surfacing the citation metadata sent by the Gemini API, the CLI now allows users to click through to the original source material, ensuring the code is safe to use and properly attributed.

## 3. How-To Guide

If you are not an Enterprise Code Assist user (or if you want to ensure the feature is explicitly on), you can enable citations via your configuration.

### Enabling via Configuration
Add or update the `showCitations` property in your Gemini CLI settings.

1.  Open your configuration file (typically `~/.gemini/config.json` or accessible via the settings command).
2.  Add the following key-value pair:

```json
{
  "showCitations": true
}
```

### What to Expect
Once enabled, when you ask a question that relies on specific external knowledge, the CLI will append sources to the response.

**Example Prompt:**
> "Explain how to use the Python `requests` library to make a POST request."

**Response:**
> ... (Explanation and code snippet) ...
>
> **Citations:**
> [1] https://requests.readthedocs.io/en/latest/user/quickstart/
