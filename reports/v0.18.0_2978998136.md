# 🚀 What's New: Anomalo Data Quality Extension for Gemini CLI

## 1. Feature Summary
We are excited to announce the release of the **Anomalo Extension for Gemini CLI**. This integration bridges the gap between your terminal and your data quality stack. Developers and Data Engineers can now query their data warehouse metadata, check table health, and investigate data quality issues directly through the Gemini CLI using both strict commands and conversational natural language.

**Key Capabilities:**
*   **Natural Language Querying:** Ask questions like *"Is the users table fresh?"* or *"Show me failing checks for the finance schema."*
*   **Metadata Retrieval:** Instantly pull schema definitions and table statistics without leaving the terminal.
*   **Quality Status:** Get real-time pass/fail status on Anomalo checks.

## 2. Background & Context
### The Problem
Data Engineers often face significant context switching. Debugging a broken pipeline usually involves:
1.  Seeing an error in the terminal/logs.
2.  Switching to a browser to log into the Anomalo dashboard.
3.  Searching for the specific table.
4.  Interpreting the visualization to find if a data quality check failed.

### The Solution
By integrating Anomalo directly into the Gemini CLI, we are "shifting left" on data observability. The goal is to make data quality insights accessible in the environment where code is written and executed.

Based on the repository (`datagravity-ai/anomalo-gemini-extension`), this change aims to:
*   **Reduce Time-to-Resolution (MTTR):** Allow engineers to verify data health immediately via CLI while debugging scripts.
*   **Leverage GenAI:** Use Gemini’s reasoning capabilities to interpret complex data quality alerts and summarize them into human-readable explanations within the console.

## 3. How-To Guide

### Prerequisites
*   Gemini CLI installed and authenticated.
*   An active Anomalo instance and an API Key.

### Step 1: Install the Extension
Run the following command in your terminal to pull the extension package:

```bash
gemini extensions install https://github.com/datagravity-ai/anomalo-gemini-extension
```

### Step 2: Configuration
Once installed, you likely need to configure your API credentials (replace with your actual instance details):

```bash
# Standard pattern for extension configuration
gemini config set anomalo.api_key "YOUR_ANOMALO_API_KEY"
gemini config set anomalo.instance_url "https://your-instance.anomalo.com"
```

### Step 3: Usage Examples

**Method A: Natural Language (Conversational)**
This is the most powerful way to use the extension. You can speak to your data warehouse health naturally.

```bash
gemini "What is the data quality status of the 'public.transactions' table?"
```
*Output:* Gemini will interpret the intent, call the Anomalo API, and return a summary: *"The 'public.transactions' table is currently healthy. However, a 'Missing Data' check passed with warnings 2 hours ago."*

**Method B: Explicit Commands**
For scripting or quick checks:

```bash
# Example command to list failing checks
gemini anomalo checks list --status failed
```

## 4. Walkthrough / Technical Deep Dive
How does the Gemini CLI talk to Anomalo? Here is the architectural flow:

1.  **Intent Recognition:** When you type `gemini "Check my table health"`, the Gemini CLI's router analyzes the request. It identifies that the context relates to data quality and routes the prompt to the installed `anomalo-gemini-extension`.
2.  **Tool Definition:** The extension provides a `manifest.json` (or equivalent tool definition) that exposes specific Anomalo API endpoints (e.g., `/api/v1/table-health`, `/api/v1/checks`) as tools available to the LLM.
3.  **API Execution:**
    *   The extension converts your natural language query into specific API calls.
    *   *Example:* "Is the data fresh?" translates to a call to the Anomalo Metadata API checking the `last_ingested_at` timestamp or specific freshness checks.
4.  **Response Synthesis:** The raw JSON response from Anomalo (which can be verbose) is fed back into Gemini. Gemini summarizes the JSON into a concise, developer-friendly response printed to `stdout`.
