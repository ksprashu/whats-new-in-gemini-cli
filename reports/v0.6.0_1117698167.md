# What’s New in Gemini CLI: Prompt Search

**Release:** *Upcoming / Recent Integration*
**Contributor:** @Aisha630
**PR Reference:** [#5539](https://github.com/google-gemini/gemini-cli/pull/5539)

## 1. Feature Summary
The Gemini CLI now supports **Reverse Prompt Search**. Users can instantly search through their session history to find previously used prompts without needing to repeatedly press the "Up" arrow or manually copy-paste from external notes.

Triggered via the standard `Ctrl+R` shortcut, this feature brings familiar shell functionality (like Bash/Zsh reverse search) directly into the Gemini conversational interface.

## 2. Background & Context
### The Problem
As users engage in longer, more complex sessions with Gemini, losing track of a specific, highly effective prompt became a friction point. Users were frequently:
*   Endlessly scrolling through history using the arrow keys.
*   Re-typing complex prompt engineering structures from scratch.
*   Losing context when switching between different interaction threads.

### Community Demand
The demand for this feature was significant. As noted in the development discussion, there were multiple attempts by the community to propose similar features. The team recognized that this was a high-priority quality-of-life update that would "delight users."

### Development Considerations
A key topic during the development (PR #5539) was the User Experience (UX) regarding **multiline prompts**. Since LLM prompts often span several paragraphs (unlike typical one-line terminal commands), the team had to ensure the search UI could handle and display these bulky history items without breaking the visual flow of the CLI.

## 3. How-To Guide

Using the Prompt Search is designed to be intuitive for anyone familiar with command-line tools.

**Prerequisites:** Ensure you have updated to the latest version of the Gemini CLI.

**Step-by-Step:**

1.  **Start the CLI:** Launch your Gemini CLI session.
    ```bash
    gemini chat
    ```
2.  **Trigger Search:** At the prompt cursor, press `Ctrl` + `R`.
    *   *The prompt indicator should change to signify "(reverse-i-search)".*
3.  **Type Your Keyword:** Begin typing a word you remember from a previous prompt (e.g., "refactor", "JSON", or a specific function name).
4.  **Browse Results:** As you type, the CLI will auto-fill the most recent matching prompt.
    *   *Note: Depending on the specific implementation, you may press `Ctrl+R` again to cycle backward through earlier matches.*
5.  **Select and Send:** Once the desired prompt appears, press `Enter` to run it immediately, or use the arrow keys to edit it before sending.

## 4. Walkthrough / Technical Deep Dive
*How it works under the hood.*

The Prompt Search feature likely integrates with the underlying `readline` interface (or the specific Node.js/Python input handling library used by the CLI).

*   **History Buffer:** The CLI maintains an array of strings representing the user's input history.
*   **Fuzzy vs. Literal Matching:** When `Ctrl+R` is pressed, the input mode switches to a search query. The system filters the History Buffer in real-time.
*   **The Multiline Challenge:**
    One of the specific engineering challenges noted in the PR was rendering **multiline prompts**.
    *   *Standard Shells:* Usually truncate history to one line in search.
    *   *Gemini CLI Implementation:* To support Prompt Engineering, the search logic has to preserve the formatting of pasted code blocks or long paragraphs. The render logic likely previews a snippet of the prompt or collapses the view until the user selects it, ensuring the terminal UI remains responsive and readable.
