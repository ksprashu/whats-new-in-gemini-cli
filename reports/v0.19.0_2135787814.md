# 🚀 What's New: Eleven Labs Integration for Gemini CLI

**Date:** October 26, 2023
**Component:** Extensions / Model Context Protocol (MCP)

## 1. Feature Summary
We are thrilled to announce the immediate availability of the **Eleven Labs Extension** for the Gemini CLI. This new extension leverages the Model Context Protocol (MCP) to bridge Gemini’s reasoning capabilities directly with Eleven Labs' industry-leading AI audio platform.

With a simple install command, developers can now instruct Gemini to create lifelike speech, manage voice history, and retrieve audio resources directly from their terminal, without needing to write custom API wrappers or leave the CLI environment.

## 2. Background & Context
**Why was this change made?**
Previously, integrating high-quality Text-to-Speech (TTS) into a CLI workflow was a fragmented process. Developers using Gemini for content generation (e.g., writing scripts, summarizing logs) had to copy that text and paste it into a web UI or write separate `curl` scripts to hit the Eleven Labs API.

**The Problem Solved:**
Based on the ecosystem shift toward the **Model Context Protocol (MCP)**, the goal was to standardize how Gemini interacts with external services. By wrapping the Eleven Labs API in an MCP server, we solve two main problems:
1.  **Context Switching:** Users no longer need to switch windows to generate audio.
2.  **Tool Use:** Gemini can now "reason" about audio. You don't just ask it to *write* a script; you can ask it to *perform* the script, and it knows which Eleven Labs tools to call to make that happen.

## 3. How-To Guide

### Prerequisites
*   Gemini CLI installed and authenticated.
*   An active [Eleven Labs API Key](https://elevenlabs.io/).

### Step 1: Install the Extension
Run the following command in your terminal to fetch and install the MCP server for Eleven Labs:

```bash
gemini extensions install https://github.com/elevenlabs/elevenlabs-mcp
```

### Step 2: Configuration
The CLI will likely prompt you for environment variables. Ensure your API key is set in your session:

```bash
export ELEVENLABS_API_KEY="your_api_key_here"
```

### Step 3: Usage Examples
Once installed, you can speak to Gemini naturally about audio tasks.

**Example A: Simple Text-to-Speech**
> **User:** "Generate an audio file where a deep British voice says: 'System diagnostics complete. All servers are green.'"
>
> **Gemini:** *Identifies the intent, calls the Eleven Labs `text_to_speech` tool, selects an appropriate voice ID, and returns the path to the generated MP3.*

**Example B: Managing Voice History**
> **User:** "List the last 5 audio tracks I generated and delete the one that was too short."
>
> **Gemini:** *Calls `get_history`, parses the list, identifies the target file based on duration/metadata, and calls `delete_history_item`.*

## 4. Walkthrough / Technical Deep Dive

This feature is built upon the **Model Context Protocol (MCP)**. Here is how the flow works under the hood:

1.  **The Server:** The extension installs a lightweight MCP server (`elevenlabs-mcp`) locally. This server defines a specific set of "Tools" (functions) that map to the Eleven Labs REST API endpoints (e.g., `POST /v1/text-to-speech/{voice_id}`).
2.  **Tool Discovery:** When you start the Gemini CLI, it connects to this server and asks, "What can you do?" The server responds with a JSON schema defining its capabilities: `generate_audio`, `get_voices`, `get_history`, etc.
3.  **The Reasoning Loop:**
    *   When you type a prompt ("Read this text..."), Gemini analyzes the request.
    *   It recognizes that it cannot generate audio natively, but it *sees* a tool description from the extension that matches the user's intent.
    *   Gemini generates a structured JSON object containing the arguments for the function (the text to speak, the voice ID).
4.  **Execution:** The Gemini CLI intercepts this JSON, passes it to the `elevenlabs-mcp` server, which executes the actual API call to Eleven Labs, downloads the audio bytes, and returns the result (or file path) back to Gemini to display to the user.
