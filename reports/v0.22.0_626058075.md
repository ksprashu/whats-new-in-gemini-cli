# 🚀 What's New: Context-Driven Development & AI-Powered Security

## 1. Feature Summary
This release marks a significant expansion of the Gemini CLI ecosystem, introducing two powerful extensions designed to shift the developer experience from simple code generation to **architectural planning** and **security compliance**.

*   **Conductor (Planning++):** A new workflow tool that introduces "Context-Driven Development." It allows Gemini to act as a technical architect, working with you to create detailed plans and artifacts before a single line of code is written.
*   **Endor Labs Integration:** A security-focused extension that brings natural language interaction to dependency management, vulnerability scanning, and code analysis.

## 2. Background & Context
### The Problem: The "Context Gap"
LLMs are excellent at generating code snippets, but they often struggle with the "Big Picture."
*   **For Conductor:** Developers found that jumping straight into coding with an LLM often led to "hallucinated architectures" or code that didn't fit existing patterns. As highlighted in the Google Developers Blog, the goal here is to **"Measure twice, implement once."** By establishing guardrails and artifacts (plans) first, the CLI ensures that subsequent code generation is grounded in a verified strategy.
*   **For Endor Labs:** Modern development relies heavily on open-source dependencies. Checking these for vulnerabilities usually requires context switching to web dashboards or running complex CI/CD scripts locally. This extension brings that data directly into the developer's terminal via natural language.

## 3. How-To Guide

### 🛠️ Setting up Conductor
**Installation:**
```bash
gemini extensions install https://github.com/gemini-cli-extensions/conductor
```

**Usage Example:**
Instead of asking Gemini to "write a python script," you engage Conductor to plan a feature.

1.  **Initiate the Plan:**
    ```bash
    gemini conductor "I want to build a microservice for processing user uploads."
    ```
2.  **Iterate:** Conductor will ask clarifying questions (e.g., "What database should we use?", "Do you need AWS S3 integration?").
3.  **Generate Artifacts:** Conductor generates a `.md` plan file acting as the blueprint.
4.  **Execute:**
    ```bash
    gemini implement --plan ./conductor-plan.md
    ```

### 🛡️ Setting up Endor Labs
**Installation:**
```bash
gemini extensions install https://github.com/endorlabs/gemini-extension
```

**Usage Example:**
Perform security checks using natural language queries against your local repository.

1.  **Check for Vulnerabilities:**
    ```bash
    gemini "Does my current project have any high-severity vulnerabilities?"
    ```
2.  **Analyze Dependencies:**
    ```bash
    gemini "Why are we using version 1.2 of the 'requests' library, and is it safe?"
    ```

## 4. Walkthrough / Technical Deep Dive

### Conductor: The Agentic Loop
Conductor operates differently than standard prompt-response interactions. It utilizes an **agentic loop** focused on retrieval and refinement.
1.  **Context Scrape:** When initialized, Conductor scans your current directory structure to understand the existing tech stack.
2.  **Recursive Querying:** If the LLM detects ambiguity in your request, it pauses generation to prompt the user for input.
3.  **Artifact Generation:** Instead of outputting code to `stdout`, it writes structured documentation (Architecture Decision Records or Implementation Plans) to the file system. These artifacts serve as the "Ground Truth" for the LLM during the implementation phase, drastically reducing hallucination.

### Endor Labs: Natural Language over API
The Endor Labs extension acts as a semantic bridge between the developer and the Endor Labs analysis engine.
1.  **Intent Recognition:** The Gemini CLI parses the user's natural language query to determine if it is a security or dependency question.
2.  **Tool Routing:** If recognized, the query is routed to the Endor extension, which triggers a scan or queries the Endor Labs API for existing project data.
3.  **Synthesis:** The raw JSON data (vulnerability reports, reachability analysis) is fed back into Gemini's context window. Gemini then summarizes this technical data into a conversational answer, highlighting specific CVEs or upgrade recommendations.
