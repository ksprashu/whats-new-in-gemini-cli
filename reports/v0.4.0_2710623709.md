# What's New in Gemini CLI: Intelligence, Editing, and Flow

This release focuses heavily on **Developer Experience (DX)**. We are introducing real-time prompt completion to speed up your queries, an experimental "Smart Edit" tool to improve code generation accuracy, and critical fixes to conversation flow management.

Here is everything you need to know about the latest changes.

---

## 1. Feature Summary

*   **✨ Real-time Prompt Completion:** The CLI now offers AI-powered suggestions to complete your sentences as you type.
*   **🛠️ Experimental Smart Edit Tool:** A new, smarter algorithm for applying code edits to your files is now available for testing.
*   **🗣️ Conversation Flow Fix:** We have patched an issue where the model would occasionally loop or "talk to itself," ensuring the user remains in control of the conversation turn.

---

## 2. Background & Context

### The Need for Speed: Prompt Completion
**PR by @3ks**
Writing detailed prompts can be repetitive. To reduce friction, we are introducing a "Ghost Text" style completion feature. This brings the IDE-like autocomplete experience directly into your terminal input, helping you formulate complex queries faster.

### Improving Code Reliability: Smart Edit
**PR by @silviojr**
Applying AI-generated diffs to existing code files is one of the hardest challenges in AI coding assistants. Sometimes, strict search-and-replace fails if context lines don't match exactly. The new `Smart Edit` functionality (visible in the codebase as `src/tools/smart-edit.ts`) aims to make the application of these edits more robust and context-aware compared to the standard edit tool.

### Stability: Stopping the "Runaway" Model
**PR by @SandyTao520**
Users reported instances where the model would utilize a workaround that encouraged it to continue the conversation on the user's behalf—effectively simulating a user reply and responding to it immediately. This created a disruptive loop. The team has removed this workaround to enforce strict turn-taking.

## 3. How-To Guide

To access these features, you will need to modify your `settings.json` configuration file.

### Enable Prompt Completion
To see AI suggestions while you type:

1.  Open your `settings.json`.
2.  Add the `enablePromptCompletion` key under the `general` object.

```json
{
  "general": {
    "enablePromptCompletion": true
  }
}
```

### Try the Experimental Smart Edit
To test the new editing logic:

1.  Open your `settings.json`.
2.  Add the `useSmartEdit` key at the root level.

```json
{
  "useSmartEdit": true
}
```
*Note: As this is experimental, please share feedback if the tool fails to apply edits correctly.*

### Manage Conversation Flow
The fix for the "model talking to itself" is applied by default. However, if this change disrupts your specific workflow or if you relied on the previous behavior, you can disable the check:

```json
{
  "skipNextSpeakerCheck": false
}
```

## 4. Walkthrough / Technical Deep Dive

Based on the file coverage reports, here is a look at how these features are implemented under the hood.

### Prompt Completion Architecture
The implementation relies heavily on `src/ui/hooks/useCompletion.ts` and `src/ui/components/Completion.tsx`.
*   **Mechanism:** As you type in the `InputPrompt`, the CLI likely debounces your keystrokes and sends a lightweight prediction request to the model.
*   **Rendering:** The suggestion is rendered as "ghost text" (faded gray text) ahead of your cursor. The code coverage in `Completion.tsx` indicates specific logic for handling these overlay states alongside the standard user input buffer.

### Smart Edit Logic
The code coverage reveals a split between `src/tools/edit.ts` (the standard editor) and `src/tools/smart-edit.ts`.
*   **Differentiation:** Standard editing often relies on strict string matching or line-number targeting. `Smart Edit` likely utilizes a more fuzzy-matching approach or an iterative "apply and verify" loop.
*   **Integration:** When `useSmartEdit` is set to true, the `ToolRegistry` likely swaps the implementation of the `edit` tool to route requests through the logic defined in `smart-edit.ts`, which may handle indentation and whitespace discrepancies more gracefully than the standard tool.
