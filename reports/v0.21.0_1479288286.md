# 🚀 What's New: Chat with your Metrics using the Rill Extension

**Date:** Oct 26, 2023
**Product:** Gemini CLI
**Release Focus:** Data Analytics & Extensions

## 1. Feature Summary
We are excited to introduce the **Rill Extension for Gemini CLI**. This integration bridges the gap between your command line and your business intelligence. Developers can now utilize natural language to query Rill projects directly from the terminal.

Instead of context-switching to a dashboard or writing manual SQL queries to check metrics, you can simply ask Gemini questions like *"What was the total revenue yesterday?"* or *"Compare active users week over week,"* and receive immediate, data-backed answers.

## 2. Background & Context
### The Problem
Rill is a powerful tool for transforming data into fast, interactive dashboards. However, access to this data has traditionally required:
1.  Navigating the Rill web UI.
2.  Manually adjusting filters and dimensions.
3.  Writing specific SQL queries for ad-hoc analysis.

For developers and data engineers working in the terminal, breaking flow to check a metric in a browser is a friction point. Furthermore, exploring data trends often requires "guessing" the right filters to apply.

### The Solution
By wrapping Rill’s API into a **Gemini Extension**, we utilize the Large Language Model's reasoning capabilities to understand the *intent* behind a question. The LLM translates natural language into Rill's semantic query structure.

This feature was prioritized to support the "Data-as-Code" philosophy—keeping the developer close to the code *and* the data generated by it, without leaving the CLI environment.

## 3. How-To Guide

### Step 1: Install the Extension
To enable Rill capabilities, you need to install the extension from the Rill Data repository. Run the following command in your terminal:

```bash
gemini extensions install https://github.com/rilldata/rill-gemini-extension
```

### Step 2: Ensure Rill Context
Make sure you have a Rill project running locally (via `rill start`) or are authenticated to a Rill Cloud project. The extension needs access to your metrics definitions.

### Step 3: Ask Questions
Once installed, start a chat session or use a one-off prompt.

**Example 1: Basic Metric Lookup**
> `@gemini What is the total number of bids in the auction dataset?`

**Example 2: Time-Based Analysis**
> `@gemini How did the bid volume change between yesterday and the day before?`

**Example 3: Dimension Breakdown**
> `@gemini Which publisher had the highest win rate last month?`

## 4. Walkthrough / Technical Deep Dive
How does Gemini know how to query your data without hallucinating? The magic lies in **Tool Calling** and Rill’s **Semantic Layer**.

1.  **Schema Discovery**: When the extension loads, Gemini retrieves the "Metrics View" definitions from your Rill project. It doesn't look at raw raw tables; it looks at the *semantic* definitions (e.g., it knows `revenue` is `SUM(price)`).
2.  **Intent Mapping**: When you ask, *"Show me trends for high-value users,"* the LLM analyzes the prompt against the available metrics and dimensions (like `user_id`, `category`, `timestamp`).
3.  **Query Generation**: Instead of generating generic PostgreSQL, the extension constructs a precise query compatible with Rill's high-speed analytical engine (DuckDB/Druid under the hood).
4.  **Execution & Interpretation**:
    *   The CLI executes the query against the running Rill instance.
    *   Rill returns a JSON payload of the results.
    *   Gemini parses this JSON and summarizes it in natural language (e.g., *"The volume increased by 15%..."*), rather than just dumping a raw table.
