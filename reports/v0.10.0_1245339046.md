## 4. Walkthrough / Technical Deep Dive

### The "Rich" Integration
Under the hood, we have refactored the `OutputManager` class to utilize the [Rich](https://github.com/Textualize/rich) Python library.

1.  **Spinner Logic:** We now wrap the `asyncio` network calls to the Gemini API within a `console.status` context manager. This ensures that the spinner runs on a separate thread, keeping the UI responsive even if the network hangs.
2.  **Markdown Parsing:** The response stream is now piped through a Markdown parser before being printed to `stdout`. This parser detects language tags (e.g., ` ```python `) and applies the appropriate ANSI color codes based on your terminal's color profile.

### Error Interceptors
We moved away from `try/except` blocks scattered across commands. We now use a **Decorator Pattern** on the main click command group.
*   The decorator intercepts `GeminiAPIError`.
*   It inspects the error code.
*   It matches it against a dictionary of "Helpful Hints" before printing the final output.
